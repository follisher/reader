# 阅读演示

在本目录执行：

```sh
flutter pub get
flutter run
```

示例书架包含 TXT、Markdown、EPUB 和 PDF 图书，也可通过右上角 `+` 多选导入本地文件。TXT 与 Markdown 请使用 UTF-8 编码。

- TXT/Markdown：提供字体、行距、主题、翻页模式、自动阅读、书签、划线与评论等功能。
- EPUB：Android/iOS 使用 Readium，支持横向分页或纵向连续阅读、目录、选区笔记与位置恢复。
- PDF：仅 Android/iOS 可阅读，支持目录、书签和上下/左右滚动。

完整接入与平台配置见上一级 [README](../README.md)。
